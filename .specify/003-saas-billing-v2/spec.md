# 003 · SaaS 计费二期（订阅 + 易支付 + 初始化赠送 + 官网云端入口）

> 状态：已定稿（含 2026-10-19 用户四项裁决）
> 覆盖关系：本 spec **显式覆盖** 002-modular-subscription 的两处口径——
> ① N1「本阶段不接任何真实支付通道」→ 本阶段接入易支付（先 mock 后真人）；
> ②「平价路线：16 收费模块合计 ¥999/年」→ 新口径「几乎全免费 + 浏览器自动化 ¥99 买断 + 软件订阅 ¥149/月」。
> 002 的架构资产（模块闸、订单状态机、MarkPaid 唯一入账口、LLM 双轨计费、tenancy）**全部沿用，不推倒**。

## 背景

一套代码同时支撑两种形态（已有实现，本阶段只补产品语义）：

| 形态 | 开关 | 定位 |
|---|---|---|
| 本地独立部署（开源版） | `TENANT_MODE=off`（+`PLATFORM_ENABLED=false`） | 默认租户单机，持续开源推广 |
| 云端 SaaS 版 | `TENANT_MODE=on`（+`PLATFORM_ENABLED=true`） | 运营方托管多租户实例，增值收费 |

云端版对外地址：**https://saas.hivemtk.cn（占位常量，上线前替换）**。

## 需求 → 决策

### R1 双形态控制（问题1）
- 决策：不新增机制。复用 `TENANT_MODE` × `PLATFORM_ENABLED`；public config 增加 `edition`（opensource|saas）与 `cloud_url` 语义字段供前端展示。
- 最低入侵原则：所有新付费能力以 `PLATFORM_ENABLED && tenant.IsMultiTenant()` 双条件 gate，离线路径零行为变化（浏览器自动化除外，见 R3）。

### R2 初始化收敛 + 静默合规采集（问题2）
- 两端（`/setup` 离线初始化、SaaS 租户注册）必填收敛为：**用户名/密码/名称(company)/负责人/电话/地址**；邮箱、执照号改选填。
- 监管告知勾选 + `agreement_version` 沿用现状（版本号如需升版由 T002 统一处理）。
- **静默采集**：初始化/注册请求落 `client_ip`、`user_agent`、设备指纹（复用 `internal/pkg/utils/fingerprint`），写入租户登记落点并随平台注册 payload 上报。不做用户可见提示，不做前端采集（服务端视角即可）。

### R3 定价与赠送（问题3）
新目录口径（平台端为运行时权威，编译期常量仅作种子）：
- 功能模块：**全部免费**（price_cents=0，注册/初始化自动赠予开通）；
- **浏览器自动化：¥99 买断**（新增 BillingCycle=`once`，9900 分，不设 ExpiresAt）；
- 软件订阅：**¥149/月，仅按月**（新增平台级订阅商品，价格后台可配）；
- LLM token：输入/输出分列定价——**已有完整实现，本阶段零代码，仅运营配置**；
- 新商户注册即 **15 天体验期**（天数可配，默认 15）；体验期等同订阅有效。
- 初始化赠送：**1 个租户级智能体 + 1 个起步资产包**（幂等 provisioning，on/off 两态都做）。
- 本地开源版：同口径全免费模块，**浏览器自动化同锁**（用户裁决；本地无支付通道 → 保持不可购不可用，不做授权码旁路）。

### R4 易支付（问题4）
- 平台端配置易支付商户信息（网关地址/pid/key，key 加密存储，env 兜底）；
- 平台端配置价格（模块价、订阅价、LLM 套餐价——后两项页面已有或将有）；
- 链路：用户端下单 → 平台端建单/发起支付（跳转表单或二维码）→ 易支付回调**验签+金额校验** → `MarkPaidForChannel` → fulfill 履约 → 用户端 sync/轮询拉到生效；
- **MOCK 模式**（`EPAY_MOCK=true`）：平台端内置模拟网关，自动回签回调，保证全流程无真人可测；上线前切真实网关做真人验收；
- 沿用 ADR-M3：线下人工确认与线上回调共用 `MarkPaid` 唯一入账口。

### R5 到期与续费墙（裁决：整站业务锁定）
- 状态机：`trial(15d) → active(按月续费顺延) → expired`；
- expired 时用户端**整站业务锁定**：白名单仅登录、public config、模块市场（浏览/订单/我的）、订阅状态与续费、支付结果查询；数据不删，续费即恢复；
- 判定：用户端镜像订阅状态（心跳/sync 下发），**平台不可达时 fail-open 用最后已知状态**（网络抖动不砖头）；平台端对 expired 商户在 merchant-auth/sync/LLM 代理层拒绝（纵深）；
- 无 cron：全部惰性判定。

### R6 官网（问题5）
- 只改内容不动 UI：新增「云端版」入口（hero/navbar/pricing CTA → saas.hivemtk.cn 占位常量，集中一处便于替换）；
- 功能特色/模块/开源信息按新定价刷新（含 gen-module-bindings 重生成 content.js）；
- `website/TERMINOLOGY.md` 修订：「云端版」从禁用词转为正式产品词（保留「代管版」禁用）；付费口径话术同步。

## 非目标（本阶段明确不做）

- 真人支付验收（留上线前人工 checklist，T031 附）；
- cron 到期扫描、优惠券、按年订阅、套餐捆绑；
- 本地授权码解锁浏览器自动化；
- LLM 计费代码改动（已完备）；
- 平台端「订单超级/分账」类财务功能（仅标准入账+履约）。
