## 1. 五层架构规范

### 规范内容
```
Router → Controller → Service → Repository → Model
```

### 评估结果

| 维度 | 评分 | 说明 |
|------|------|------|
| 合理性 | 5/5 | 符合 Go 语言最佳实践，职责清晰 |

| 可执行性 | 5/5 | 可通过静态分析工具检测跨层调用 |

2. **缺少 Context 传递规范** — 未说明 `context.Context` 的使用规范
   - 建议：明确 Context 的传递方式和禁止事项
