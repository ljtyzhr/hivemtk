## 4. 改进建议

### 4.1 规范文档更新（高优先级）

1. **补充辅助层定义**
   - `dto/` — 数据传输对象，禁止包含业务逻辑
   - `middleware/` — 中间件，禁止直接操作 DB
   - `pkg/` — 公共工具包，禁止依赖业务层

2. **补充特殊路由规范**
   - 健康检查：`/health`、`/healthz`、`/readyz`
   - WebSocket：`/ws/*`
   - 文件服务：`/files/*`
   - 调试路由：`/__debug__/*`

3. **补充业务错误码**
   - 范围：10000-19999
   - 示例：10001=用户不存在

4. **补充 Context 传递规范**
   - 禁止在 Service 层创建新的 Context
   - 必须从 Controller 层传递 Context

### 4.2 代码修复（高优先级）

**Service 层重构：** 将 151 个直接持有 `*gorm.DB` 的函数重构为通过 Repository 层访问数据库。

**重构策略：**
1. 构造函数改为接受 Repository 接口而非 `*gorm.DB`
2. 方法签名移除 `*gorm.DB` 参数
3. DB 操作统一通过 Repository 层执行

**预估工作量：** 大型重构，涉及 40+ 文件，建议分阶段执行。
